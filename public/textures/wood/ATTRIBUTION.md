# Wood textures

Photos of real wood, one per species the designer offers. Each file is a crop of the source,
turned so the grain runs along its width, with its two ends cross-faded so it wraps round the band
without a seam, its uneven lighting along the width evened out, and its colour balanced toward the
colour the app lists for that wood (oiled). Some pale veneers had their contrast raised a little.
1024 × 256 WebP. Each file keeps its source's license.
